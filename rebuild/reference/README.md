# Reference bitstreams

Known-good encrypted/compressed F2 bitstreams remain outside this development directory.

Observed examples:
- fpgaminer_top_odo_1786752000.bit
- fpgaminer_top_odo_1787616000.bit
- fpgaminer_top_odo_1788480000.bit

The timestamps are separated by 864000 seconds (10 days).

Use these as behavioral/hardware references. Do not attempt to commit decrypted material or overwrite the originals.
